PWS

My PWS project was to make my own electromotor. I got the idea for this in the previous months' classes when we got explained how Lorentz force works, in that class I made the drawing for the first prototype. In the following months I grew the project into what would eventually become my final version, which you can see in the image. It is a non-commutated dc motor, with a 3d printed stator and rotor and the hardware and the wire was gotten from the hardware store.

Ti-Basic

Ti-Basic is the programming language for Texas Instruments' graphical calculators. It is more capable than you'd think at first glance, however it is extremely held back by it's hardware limitations. The process for writing the code is longwinded and the code execution speed is slow, but working around those limits taught me multiple coding styles that help with optimisation and edgecase solving. I will probably not be writing much more in Ti-Basic, but the experience is valueable.

Minecraft stuff: datapacks and mods

I started making datapacks for the Origins mod, a mod that lets you choose a certain 'origin' when you start a new world which all have differnt powers and limitations. I've made 10+ fully custom origins and made edited versions of many others, for myself and my friends on our different servers. Since then I made a few other simple datapacks for general game things. I also usually was the one in charge of putting together modpacks, solving the compatibility issues between certain mods and also doing the server-side setup.

AHK

AutoHotKey is a nice little language / program focused on making user interaction to the wishes of the user, not making the user have to conform to the machine.
It's main use in generally making one button function like another, however complex functions are possible. It also has functions to compile scripts to stand-alone excutables, which was useful for distribution to friends who were playing the same games as me and had the same keybind struggles.

Processing

Processing is a Java-based programming language made to simplify teaching coding to newer generations of programmers. It's main focus is on graphical implementations, yet since it's interpreted and not compiled it's slower than java. Programming in Processing feels like a mix between the ease of python, but with a bit of TI-Basic's unneccesary complexity mixed in. For my creature I took inspiration from the wiggly worm website. And I made a few extra projects for fun.
